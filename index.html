Guía para el Docente

Cómo crear o personalizar ejercicios en el programa

El programa está diseñado con una arquitectura modular por materia:

  • materias.js: Define las asignaturas disponibles (código, nombre, unidades temáticas e íconos).
  • ejercicios.js: Banco de problemas para Electrónica I (3703).
  • ejercicios_tc3.js: Banco de problemas para Teoría de Circuitos III (3709).
  • Para agregar una nueva asignatura o tema, basta con registrarla en materias.js y crear su archivo de ejercicios.
// Estructura de cada ejercicio:
{
  id: "bjt-nuevo-01",
  categoria: "bjt", // 'cc', 'diodos', 'bjt'
  titulo: "Nombre del ejercicio",
  dificultad: "Fácil" | "Media" | "Avanzada",
  enunciado: "Texto con fórmulas LaTeX $V_{CC} = 12\\text{ V}$...",
  datos: [{ clave: "V_S", valor: "12 V" }],
  circuitoSvg: `<svg ...>...</svg>`,
  pasos: [
    {
      id: "paso-1",
      titulo: "Paso 1: Calcular I_B",
      pregunta: "Plantea la malla de entrada...",
      simbolo: "I_B",
      unidad: "μA",
      valorEsperado: 25.5,
      tolerancia: 0.05, // 5% de margen numérico
      pistas: [
        "💡 Pista 1 (Concepto): ...",
        "📐 Pista 2 (Ecuación): ...",
        "🔢 Pista 3 (Cálculo): ..."
      ],
      explicacionPaso: "Resolución teórica completa..."
    }
  ]
}
💡 Características para los alumnos:
  • Pistas multinivel: Pueden pedir hasta 3 pistas por paso si se traban, sin regalarles la respuesta de inmediato.
  • Tolerancia de redondeo: Acepta coma o punto decimal y margen configurable de error para evitar frustraciones de decimales.
  • Portabilidad total: Funciona directamente abriendo el archivo index.html en Google Chrome, Edge o Firefox, o subiéndolo gratis a GitHub Pages.
